# Описания изменений

Самыми дорогими операцими, на мой взгляд, являются коммиты и запросы в бд на каждом customer и lead. 
Для оптимизации запросов на чтение я заменил select запросы на каждой итерации циклов на один select запрос 
перед началом их работы, а затем все последующие обращения за данными происходят в созданный индекс, 
хранящийся в памяти. С рассчетом на 50 тыс. записей и примерным размером каждой из них около 2 КБ 
все данные должны занимать до нескольких сотен мегабайт, что достаточно приемлемо. 
Для оптимизации коммитов я объединил их в батчи, благодаря которым 
можно заливать множество изменений за раз.
